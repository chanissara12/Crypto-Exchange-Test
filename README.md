# Crypto Exchange Test

## Description

A Node.js application for testing crypto exchange 

## Prerequisites

- [Node.js](https://nodejs.org/) (v14.x or higher recommended)
- npm (comes with Node.js) or Yarn

## Installation

Install the required dependencies:

   ```bash
   npm install
   ```

## Pre-use setup

1. Change Postgresql database connectionstring at at /seed/generate-pg.js
2. run node generate-pg.js in terminal to generate seed data

## Usage

To start the application, run:

```bash
npm start
```
